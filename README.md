# 🔍 TruthLens

TruthLens is an AI-powered forensic analysis and fact-checking engine designed to detect deepfakes, manipulated media, and misinformation.

This project was built for the **SRM Hackathon**.

## 🚀 Features

- **Multimodal Analysis**: Analyze text claims, URLs, and images (deepfake detection).
- **Multilingual Support**: Supports multiple languages including English, Hindi, and Tamil.
- **AI-Powered Fact-Checking**: Leverages advanced forensic signals to determine the authenticity of forwarded messages and media.
- **Beautiful Dashboard**: A modern, sleek user interface for viewing detailed truth reports.

## 📂 Project Structure

This repository is organized as a monorepo containing both the frontend and backend applications:

- **`frontend/`**: The user interface, built with React, Vite, and modern UI components.
- **`backend/`**: The API services handling the forensic AI analysis, built with Node.js and Express.

## 🛠️ Getting Started

### 1. Frontend Setup
Navigate to the frontend directory to run the React application:
```bash
cd frontend
npm install
npm run dev
```

### 2. Backend Setup
Navigate to the backend directory to start the API server:
```bash
cd backend
npm install
npm run dev
```
